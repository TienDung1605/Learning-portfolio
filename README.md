# My learning portfolio for SQL, Python, data analysis, automation and applied AI in e-commerce.
# Learning Portfolio

## Giới thiệu

Đây là portfolio học tập của tôi trong lĩnh vực CNTT,
tập trung vào phân tích dữ liệu, tự động hóa và AI ứng dụng
cho thương mại điện tử.

## Mục tiêu

- Học và sử dụng SQL để phân tích dữ liệu bán hàng.
- Học Python để làm sạch dữ liệu và tự động hóa báo cáo.
- Xây dựng dashboard kinh doanh.
- Tìm hiểu AI ứng dụng và phân tích phản hồi khách hàng.
- Xây dựng các dự án có thể trình diễn.

## Lộ trình học

1. SQL nền tảng
2. Python cho phân tích dữ liệu
3. Dashboard với Power BI
4. AI ứng dụng
5. API, Cloud và Git
6. JavaScript/TypeScript nếu cần

## Thời gian học

Dự kiến: 5–7 giờ mỗi tuần.

## Các dự án dự kiến

- Phân tích hiệu quả bán hàng bằng SQL
- Tự động hóa báo cáo kinh doanh bằng Python
- Dashboard thương mại điện tử
- Phân tích phản hồi khách hàng bằng AI

## Nguyên tắc học

- Tự làm trước, hỏi gợi ý sau.
- Không sao chép code mà mình không thể giải thích.
- Không đưa dữ liệu khách hàng hoặc dữ liệu công ty thật lên GitHub.
- Mỗi dự án phải có bài toán, dữ liệu, cách làm, kết quả, đề xuất và hạn chế.
